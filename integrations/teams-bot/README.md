# App de Microsoft Teams

- `manifest.template.json`: manifiesto con variables (`${BOT_APP_ID}`, `${BACKEND_HOST}`, ...).
- `color.png` / `outline.png`: íconos de 192×192 y 32×32.
- `package.sh`: genera `manifest.zip` listo para cargar en Teams.
